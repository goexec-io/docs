O aplicativo foi pensado para o que você faz **com a instalação pronta**:
acionar, acompanhar, receber o aviso, ajustar uma regra. Montar a instalação —
mapear pinos, convidar gente, emitir credenciais — pede tela grande e fica no
painel web.

## Só no painel web

| Assunto | O que fica no painel |
|---|---|
| **Placas** | Editar as entradas e saídas, os periféricos e os limiares de um canal; travar a transferência; excluir de vez |
| **Cadastro** | Os códigos de ativação usados no gravador |
| **Câmera** | A seção Câmera da placa, as fotos, e criar ou ajustar a ação **Capturar foto** |
| **Automações** | O histórico de cada regra |
| **Organização** | Membros, convites e papéis |
| **Segurança** | Ligar e desligar a verificação em duas etapas |
| **Integrações** | Emitir chaves de API e a seção API do painel |

O aplicativo também não troca de organização: ele mostra a organização em que
você entrou, no cartão do alto da aba **Mais**. Para usar outra, saia e entre
com a outra conta.

## Os limites do beta

- **Fora das lojas.** Por enquanto a instalação é pelo convite do programa de
  [beta testers](/aplicativo/o-aplicativo/#quero-ser-beta-tester).
- **Só na vertical.** O aplicativo roda em iPhone, iPad e Android, sempre com a
  tela em pé.
- **Sem acesso por biometria.** A sessão fica guardada no celular, mas o
  aplicativo não pede digital nem rosto para abrir.
- **Sem uso offline.** Sem sinal, a tela mostra o que tinha e avisa que os
  dados podem estar velhos; comando não fica guardado para depois.

Achou um defeito, sentiu falta de algo? É exatamente para isso que o beta
existe: responda ao e-mail do convite, ou escreva para
[support@goexec.io](mailto:support@goexec.io), dizendo o modelo do celular e a
versão que aparece em **Mais → Configurações → Sobre esta versão**.
